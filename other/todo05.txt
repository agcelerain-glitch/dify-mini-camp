===========================================================
 todo05 — バグ報告機能（DB保存 + Discord Webhook）
 対象コミット: feat: バグ報告機能実装
===========================================================

■ 概要
 ナビバーに「🐛 報告」ボタンを追加。
 ユーザーが件名・内容を入力して送信すると、
 ① Supabase bug_reports テーブルに保存
 ② Discord チャンネルに Webhook 通知が届く

===========================================================
 STEP A: Supabase — テーブル作成
===========================================================

【作業場所】Supabase ダッシュボード → SQL Editor

【実行するSQL】
  database/schema/05_bug_reports.sql の内容をそのまま貼り付けて「Run」

【確認】
  Table Editor に bug_reports テーブルが表示されれば OK
  カラム: id, user_id, subject, content, created_at

===========================================================
 STEP B: Discord — Webhook URL の取得
===========================================================

【手順】
  1. Discord を開く（ブラウザ版 or アプリ）
  2. バグ報告を受け取りたいサーバーのチャンネル（例: #bug-reports）を開く
  3. チャンネル名を右クリック → 「チャンネルの編集」
  4. 左メニュー「連携サービス」→「ウェブフック」→「新しいウェブフック」
  5. 名前を設定（例: Dify mini Camp Bug Bot）
  6. 「ウェブフックURLをコピー」をクリック
     → 形式: https://discord.com/api/webhooks/XXXXXXXXXX/XXXXXXXXXXXXXXXXXXXXXXXX

【注意】
  このURLは秘密情報です。公開リポジトリに絶対に貼らないこと。

===========================================================
 STEP C: Vercel — 環境変数の登録
===========================================================

【作業場所】Vercel ダッシュボード → プロジェクト → Settings → Environment Variables

【追加する変数】
  名前:  DISCORD_WEBHOOK_URL
  値:    https://discord.com/api/webhooks/XXXXXXXXXX/XXXX... （STEP B でコピーした URL）
  環境:  Production / Preview / Development すべてにチェック

【保存後】
  「Deployments」タブ → 最新デプロイを「Redeploy」 で環境変数を反映させる
  ※ 環境変数の変更は再デプロイ後に有効になる

===========================================================
 STEP D: ローカル開発環境（任意）
===========================================================

【front/.env.local に追記】
  DISCORD_WEBHOOK_URL=https://discord.com/api/webhooks/XXXXXXXXXX/XXXX...

【注意】
  .env.local は .gitignore 対象なので Git にはコミットされない（安全）
  DISCORD_WEBHOOK_URL は NEXT_PUBLIC_ プレフィックスなし = サーバーサイド専用

===========================================================
 STEP E: 動作確認チェックリスト
===========================================================

  [ ] Supabase の bug_reports テーブルが作成されている
  [ ] Discord Webhook URL が Vercel 環境変数に登録されている
  [ ] Vercel を再デプロイしている
  [ ] ナビバーに「🐛 報告」ボタンが表示されている（ログイン時のみ）
  [ ] 件名・内容を入力して「報告する」を押すと「✅ 報告を受け付けました」が表示される
  [ ] Supabase Table Editor の bug_reports に1行追加されている
  [ ] Discord の指定チャンネルに埋め込みメッセージが届いている

===========================================================
 Discord メッセージの内容（参考）
===========================================================

  🐛 バグ報告
  件名:     フェーズ3のページが表示されない
  内容:     キャンプページからフェーズ3をクリックすると...
  ユーザーID: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
  メール:   user@example.com
  （タイムスタンプ）

===========================================================
 注意事項
===========================================================

  - DISCORD_WEBHOOK_URL が未設定でも DB 保存は成功する（通知のみスキップ）
  - Discord 通知が失敗しても 200 OK を返す設計（DB 保存を優先）
  - ユーザーは自分の報告を画面から確認できない（開発者が Supabase Studio で確認）
  - RLS により INSERT のみ許可、他ユーザーのデータは読み取り不可
